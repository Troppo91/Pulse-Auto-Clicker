💎 PULSE: Apex Elite Macro Suite
A high-precision, low-profile automation engine for Windows.

PULSE is a definitive automation suite built for users who require frame-perfect accuracy and human-like movement in their macros. Developed with a focus on both power and stealth, PULSE features an advanced Bezier-based mouse smoothing engine and dynamic randomization to bypass basic pattern-recognition systems.

🚀 Key Technical Features
16-Slot Command Center: Store, rename, and manage a massive library of macro sequences in a streamlined midnight-blue UI.

Ghost Path (Bezier) Smoothing: Mimics organic human mouse movement using randomized arc paths instead of linear "snap" movement.

Smart Range Delay (Humanizer): Randomizes click intervals within a user-defined range for ultra-stealthy auto-clicking.

Frame-Perfect Recording: Captured using hardware-level timestamps and a zero-loss queued listener to ensure no keystrokes or mouse states are dropped.

Visual HUD Overlay: Real-time, non-intrusive transparent HUD that flashes glowing indicators at click coordinates for easy macro debugging.

Sonic Feedback System: Intuitive audio cues (high/low frequency blips) provide instant status updates for headless operations (when in-game).

Global Persistence Logic: Automatically saves and syncs every toggle, slider, and keybind to custom profile snapshots.

🎹 Controls
[ESC] — Global Panic Halt (Emergency System Kill)

[F6] — Initialize Auto-Clicker

[F10] — Capture Macro Sequence

[Right-Click] — Rename Slot

🛠️ Built With
Python 3.x

CustomTkinter: Modernized UI Framework

Pynput & Keyboard: Hardware-level hook management

PyDirectInput: Low-level DirectInput driver compatibility
